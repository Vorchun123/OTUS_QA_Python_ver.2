# Logs — анализ логов веб-сервера

Скрипт на Python для анализа лог-файлов (`access.log`).

## Возможности

- Анализ конкретного файла или всех `*.log` внутри директории.
- Сбор статистики:
  - общее количество запросов;
  - количество запросов по HTTP-методам (GET, POST, PUT, DELETE, OPTIONS, HEAD);
  - топ-3 IP-адресов по количеству запросов;
  - топ-3 самых долгих запросов (метод, URL, IP, длительность, дата/время).
- Сохранение статистики в JSON и вывод в терминал.


## Формат лог-файла


```
%h - - %t "%r" %s %b "%{Referer}" "%{User-Agent}" %d
```

| Поле            | Описание                                             |
|-----------------|------------------------------------------------------|
| `%h`            | IP-адрес удалённого хоста                            |
| `%t`            | Время получения запроса                              |
| `%r`            | Тип запроса, содержимое и версия протокола           |
| `%s`            | Код состояния HTTP                                   |
| `%b`            | Количество отданных сервером байт                    |
| `%{Referer}`    | URL-источник запроса                                 |
| `%{User-Agent}` | HTTP-заголовок с информацией о клиенте               |
| `%d`            | Длительность запроса в миллисекундах                 |

Строки, не соответствующие формату, пропускаются.

## Требования

- Python 3.7+
- Только стандартная библиотека (`re`, `json`, `argparse`, `pathlib`, `collections`)

## Использование

```bash
# Анализ директории по умолчанию
python log_analyzer.py

# Анализ конкретной директории
python log_analyzer.py -p "D:\Учеба\OTUS\OTUS_QA_Python_ver.2\logs"

# Анализ одного файла
python log_analyzer.py -p "D:\Учеба\OTUS\OTUS_QA_Python_ver.2\logs"

# Сохранение JSON в отдельную директорию
python log_analyzer.py -p "D:\Учеба\Python\Log" -o "D:\Учеба\Python\Reports"
```

## Параметры командной строки

| Параметр          | Описание                                                              |
|-------------------|-----------------------------------------------------------------------|
| `-p`, `--path`    | Путь к директории с логами или к конкретному файлу                    |
| `-o`, `--output`  | Директория для JSON-отчётов (по умолчанию — рядом с лог-файлами)      |
| `-h`, `--help`    | Справка                                                               |

## Как это работает

1. Путь из `--path` проверяется через `pathlib.Path.exists()`.
2. Если это директория — отбираются все файлы с расширением `.log`;
   если файл — обрабатывается только он.
3. Каждый файл читается построчно. Строка проверяется регулярным
   выражением `LOG_PATTERN`.
4. По мере разбора накапливаются счётчики `Counter`:
   - общее количество запросов;
   - запросы по HTTP-методам;
   - запросы по IP.
   Все запросы также попадают в список `slow_requests`.
5. По завершении:
   - `Counter.most_common(3)` даёт топ-3 IP;
   - `sorted(..., reverse=True)[:3]` даёт топ-3 самых долгих запросов.
6. Результат выводится в терминал и сохраняется в
   `<имя_лога>_stats.json` в формате JSON.

## Соответствие требованиям задания

| Требование                                              | Реализация                              |
|---------------------------------------------------------|-----------------------------------------|
| Указать директорию или конкретный файл                  | `-p/--path`                    |
| Обработка всех логов в директории                       | `collect_log_files()`                   |
| Общее количество запросов                               | `total_requests`                        |
| Количество запросов по HTTP-методам                     | `methods`            |
| Топ-3 IP                                                | `top_ips`                               |
| Топ-3 самых долгих запросов                             | `top_slow_requests`                     |
| Сохранение в JSON + вывод в терминал                    | `save_statistics()` + `print_statistics()` |
| Отдельный JSON и вывод на каждый лог-файл               | Цикл `for log_file in log_files`         |
